# 🎬 Personalized Recommendation Intelligence Platform

> **Project  — Production-Style Movie Recommendation Engine & Analytics Dashboard**

A production-style movie recommendation platform built with **Python, FastAPI, Scikit-Learn/SciPy, MovieLens Data**, and a modern **Antigravity-inspired frontend**.

The platform combines a multi-stage recommendation engine with a complete movie discovery experience, personalized recommendations, user feedback, authentication, analytics, movie links, and a responsive Day/Night interface.

# 🎬 Movie Experience

The application is designed as a complete movie discovery and recommendation platform.

### 🎥 Movie Catalog

Users can:

- Browse movies
- Search movies
- Filter by genre
- Sort movies
- View movie information
- View ratings
- View genres
- View release year
- Access available movie links

Each movie card can display the movie title along with its available movie link directly underneath it.
